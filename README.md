# ClipSearch

Программа для Windows 10 и 11: ищет клипы Twitch у нескольких стримеров, в категориях и у нужных авторов за любой период и скачивает их в 1080p, 720p или 480p.

## Сайт

Искать клипы можно прямо в браузере: https://clipsearch-app.github.io/ClipSearch/

## Скачать

- [ClipSearchSetup.exe](https://github.com/clipsearch-app/ClipSearch/releases/latest/download/ClipSearchSetup.exe) — установщик (рекомендуется)
- [ClipSearch-win32-x64.zip](https://github.com/clipsearch-app/ClipSearch/releases/latest/download/ClipSearch-win32-x64.zip) — без установки

Все версии — на странице [Releases](https://github.com/clipsearch-app/ClipSearch/releases).

Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»: у программы нет платной цифровой подписи.

## Что умеет

- Несколько стримеров, категорий и авторов клипов в одном поиске.
- Период от часа до всего времени или точные даты; глубокий поиск по годам.
- Слова из названия и исключения «-слово», минимум просмотров.
- График «Когда сняты клипы», превью, встроенный плеер с вырезанием фрагмента.
- Очередь загрузок, горячие клавиши, копирование ссылок и сохранение списка в CSV.
- Обновления внутри программы.

Ключи Twitch и вход в аккаунт не нужны.

## Как устроено

Весь код программы — в одном файле `clip_search.py` (окно на WebView2 и установщик лежат в нём в упакованном виде). Сборку exe и публикацию релизов делает GitHub Actions: `.github/workflows/build-exe.yml`.

ClipSearch — независимая программа, не связана с Twitch.
